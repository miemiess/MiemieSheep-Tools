# MMyio Project

MMyio is a Python application built using PySide6, designed to provide a user-friendly interface for managing and monitoring various functionalities.

## Features

- Intuitive user interface built with PySide6.
- Modular design with separate components for UI, widgets, and resources.
- Unit tests to ensure functionality and reliability.

## Installation

To get started with MMyio, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   cd MMyio
   ```

2. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

## Usage

To run the application, execute the following command:

```
python src/main.py
```

This will launch the main window of the application.
